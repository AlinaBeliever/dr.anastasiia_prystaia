# Dr. Prystaia — proctology

Сайт лікарки-колопроктолога Анастасії Пристаї. Публікується папка `site/`.

## Адмінка (`/admin/`)

Анастасія редагує сайт сама за адресою **https://<домен>/admin/** — без коду.

| Розділ адмінки | Що змінює на сайті | Файл |
|---|---|---|
| 💳 Послуги та ціни | таблиця «Послуги й вартість» | `content/services.json` |
| 🎓 Вебінари й освітні продукти | картки в «Поглибити» (вебінар, курс, гайд…) | `content/webinars.json` |
| 🏅 Професійні досягнення | цифри й факти в «Про мене» (освіта, нагороди…) | `content/achievements.json` |
| 📰 Публікації та медіа | відео, подкасти, статті в «Поглибити» | `content/media.json` |
| 📅 Графік і запис | оголошення, клініка, телефони, графік, онлайн-бесіда, форма | `content/booking.json` |

У кожного елемента є перемикач **«Показувати на сайті»** (сховати без видалення), порядок змінюється перетягуванням.
Нові елементи рендеряться тими самими шаблонами (`tools/build/build.mjs`), тож завжди мають однаковий стиль.
Прості позначки в текстах: `**жирний**`, `[текст](https://посилання)`, `[УТОЧНИТИ]` → жовта плашка.

**Як це працює:** «Опублікувати» в адмінці = коміт у GitHub → Netlify запускає `node tools/build/build.mjs` → через ~1 хв сайт оновлено.
HTML у `site/` тепер генерується: правте шаблони в `tools/build/`, а тексти — в `content/` (або через адмінку), не HTML напряму.

Адмінка працює на [Sveltia CMS](https://github.com/sveltia/sveltia-cms) (сумісна з Decap), інтерфейс українською.

**Вхід за GitHub-токеном (на сайті):**
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `dr.anastasiia_prystaia`. Permissions → Repository → **Contents: Read and write**. Термін дії — на ваш вибір (напр. 1 рік).
3. Відкрийте `https://<домен>/admin/` → **«Увійти за допомогою токена доступу»** → вставте токен. Браузер запам'ятає вхід.
Анастасії потрібен власний акаунт GitHub (додайте її в репозиторій: Settings → Collaborators) і свій токен. Токен — як пароль: нікому не пересилати.

**Перевірка на своєму Mac (без GitHub і без інтернет-публікації):**
1. Двічі клікніть `start-site.command` (або `cd site && python3 -m http.server 8080`).
2. Відкрийте в **Chrome** `http://localhost:8080/admin/` → **«Працювати з локальним репозиторієм»** → оберіть папку проєкту `dr.anastasiia_prystaia`.
3. Змініть щось і збережіть: зміниться файл у `content/`. Щоб побачити результат на сайті, виконайте `node tools/build/build.mjs` (або перезапустіть `start-site.command`) і оновіть `http://localhost:8080`.
